# 瞬間伊作文

日本語を見て、イタリア語に瞬時に訳す練習をするためのWebアプリです。

## 概要

- 日本語とイタリア語の例文を50問収録(増やす予定)
- 解答の表示・非表示を切り替え可能
- イタリア語の音声再生
- 文法カテゴリによる絞り込み
- 問題ごとの完了チェック
- イタリア語の文をクリックすると、文法・単語・英語との対応を解説するカードを表示

## 使い方

1. `index.html` をブラウザで開きます。
2. 日本語の文を見て、イタリア語に訳してみます。
3. 「解答表示」で答えを確認します。
4. イタリア語の文をクリックして、解説を確認します。
5. 音声ボタンで発音を聞き、完了チェックを付けます。

## 使用技術

- HTML
- CSS
- JavaScript
- JSON
- Web Speech API（音声読み上げ）

## AIの利用について

本プロジェクトは、企画・設計・実装・例文および解説データの作成に至るまで、すべてAIを利用して作成しました。
